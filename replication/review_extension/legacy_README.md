# Retained earlier diagnostic

This directory contains the earlier 2011–2026 retrospective calculations and
their original verification record. They support the long-history and
calibration-sensitivity statements in the current paper. They are not the
current investment evaluation. The current results are in
`review_extension/results/`, and the current manuscript is in `paper_revision/`.

`analysis_15y.py` rebuilds the earlier results; `make_exhibits.py` rebuilds the
original exhibits, including the physical-price-and-risk figure reused in the
current manuscript. The earlier verification record refers to the previous
manuscript version, whose PDF is not duplicated in this archive.
