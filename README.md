# GPR and strategic metals

Data and empirical models for geopolitical risk, strategic metal prices and ETF returns.

## Current publication status

The repository currently contains the saved standalone research scripts,
their two accompanying READMEs, and the dependencies of the reorganised project.

| File | Saved research component |
| --- | --- |
| legacy/standalone/ree_gpr.py | Monthly ETF returns and GPR |
| legacy/standalone/ree_var.py | GPR–ETF VAR, IRFs and diagnostics |
| legacy/standalone/ree_trading.py | Historical monthly trading analysis |
| legacy/standalone/spy_gpr_excess.py | SPY excess-return analysis |
| legacy/standalone/etf_gpr_forecast.py | ETF screening and expanding forecasts |

The historical scripts use the directory layouts and additional dependencies
described in their original documentation.

The complete raw-data, processed-data, models, results, article and replication
packages have been prepared for import. They are not yet published on main.
The local execution environment failed, and the proposed one-time GitHub Actions
import needs explicit approval for repository-write permission and a push to main.

Review the exact scope, importer and proposed workflow in
[docs/GITHUB_IMPORT_PROPOSAL.md](docs/GITHUB_IMPORT_PROPOSAL.md).
