# Saved GPR project import

Imported from the existing research packages on 23 November 2026.
The underlying data retain the snapshot dates recorded in the original packages.

The reorganised project is at the repository root. The complete original
English replication is in replication/, the LaTeX source is in paper/latex/,
the three article PDFs are in paper/, and all eight earlier projects plus
the standalone files are in legacy/.

IMPORT_MANIFEST.csv records all 951 source files and their SHA-256 digests.
README_data_models_snapshot.md preserves the unedited original root README.
Identical data retain both original paths; Git deduplicates identical contents.

The import does not refresh the datasets or rerun the full model search.
The existing independent checks are run with python run.py --check.
Results and source integrity are recorded in checks/github_import_validation.json.
